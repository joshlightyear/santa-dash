# 🎅 Santa Dash - Dodge the Reindeer Poop! 💩

Welcome to **Santa Dash**, the hilarious endless runner game where Santa must duck to avoid reindeer poop falling from above!

## 🎮 How to Play

### Starting the Game
1. Open `index.html` in your web browser (Chrome, Firefox, Safari, Edge - any modern browser works!)
2. Click the "Start Game" button
3. Get ready to dash!

### Controls
- **Desktop**: Press the **DOWN ARROW** or **S** key to make Santa duck
- **Mobile/Touch**: Tap the **DUCK** button on screen

### Objective
- **Dodge the poop**: A reindeer flies overhead dropping poop - duck to avoid it!
- **Collect presents**: Grab the red and gold presents for bonus points (+50 points each)
- **Survive as long as possible**: The game gets faster over time!
- **Beat your high score**: Your best score is saved automatically

### Scoring
- **+1 point** every second you survive
- **+10 points** for each poop you successfully dodge
- **+50 points** for each present you collect

## 🌟 Tips for High Scores

1. **Timing is everything**: Don't duck too early or too late!
2. **Collect presents**: They're worth 5x more than just dodging
3. **Stay calm**: The game speeds up, but panicking makes it harder
4. **Practice**: Your first few runs will help you learn the timing
5. **Watch the reindeer**: Its position tells you when poop is coming

## 🛠️ Customization Ideas

## 🐛 Troubleshooting

**Game won't start?**
- Make sure JavaScript is enabled in your browser
- Try a different browser (Chrome recommended)
- Check that all three files (html, js, css) are in the same folder

**Controls not working?**
- Click on the game canvas to make sure it's focused
- On mobile, use the on-screen DUCK button
- Try refreshing the page

**Game running too slow/fast?**
- Close other browser tabs
- Adjust the `gameSpeed` value in game.js
- Make sure your browser is up to date

## 📱 Mobile Optimization

The game works great on phones and tablets! For the best mobile experience:
- Play in landscape mode for a better view
- Use the big DUCK button on screen
- Turn off notifications to avoid interruptions
